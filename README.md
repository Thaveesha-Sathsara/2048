# 2048
A basic 2048 game clone made using Python and Pygame, with smooth tile movement and simple game-over detection.

### 1. Installation

clone the repository:
git clone https://github.com/Thaveesha-Sathsara/2048.git

install dependancies:
pip install -r requirnments.txt


### 2. Run the game

run the game using
python main.py
